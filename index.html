Process

Three steps. Under two minutes.

From printed sheet to confirmed measurement — no prior training needed.

Step 01

Print & assemble

Download the A4 marker sheet. Print at 100% scale on paper-backed adhesive tape stock. Cut the centre ruler strip and four wrap bands. Apply to body.

Scale baked in: 40 mm centre ticks, 25 mm band ticks. Caliper-verify every batch (±0.2 mm tolerance).
Step 02

Capture front + side

Stand against a light wall. Chest height, 2 m away, phone level. Front photo then side photo. Breathe out fully before each shot.

App enforces: wall uniformity, framing, levelness, end-exhale capture timing. Loose clothing is rejected.
Step 03

Read + confirm

App reads the strip numbers at each band overlap. You read them too. If app and human agree within 20 mm — confirmed. If not — flagged for review.

Human-in-the-loop: dual-readout catches silent errors. The confirmation screen shows both values side by side.

Capabilities

Built for real conditions

The pipeline handles what自拍don't — slouch, missing markers, tilted bands, loose clothing.

Slouch-tolerant labelling

Shoulder row detected by x-position sort, not y-order. A slouching subject shifts marker heights — the app handles it without guessing.

Fail-loudly quality gates

Missing marker → count check + skip dependent measurements. Level mismatch → degrade confidence. Scale not found → error, not estimate.

Dual-readout agreement

Customer reads each band. App reads each band. Divergence > 20 mm is flagged for manual review. The customer never gets a wrong confirmation.

Light-wall pre-check

Plain background is enforced. App checks wall uniformity (stddev of grayscale pixels) before capture. No silhouette extraction from textured walls.

API

Run it in three lines

The pipeline is a Python package. Import, call, get JSON + annotated images.

# Install
$ pip install dsv

# Run on a front + side photo pair
from dsv.pipeline import run

result = run('front.jpg', 'side.jpg', out_dir='results/')

# result.measurements keys:
# across_shoulder_mm · bust_girth_mm · waist_girth_mm · hip_girth_mm ...

print(result.measurements['bust_girth_mm'])
# {'value': 892.3, 'confidence': 'high', 'human_read_mm': 890, 'app_read_mm': 892, 'agree': True}

print(result.agreement)
# 'pass' if all girths agree within 20 mm; 'review' if flagged
